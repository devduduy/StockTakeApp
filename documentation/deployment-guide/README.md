## Mengedit dokumen

Buka file `.docx` di Microsoft Word. Judul, paragraf, langkah kerja, dan tabel dapat diedit langsung. Screenshot tersimpan sebagai gambar dan dapat diganti melalui Change Picture.

DFD dan flowchart menggunakan bentuk, panah, dan kotak teks Word. Gunakan Selection Pane untuk memilih objek yang berdekatan. Sumber diagram `.drawio` juga disertakan jika lebih nyaman mengedit dengan diagrams.net.

Simpan salinan sebelum mengedit. Periksa kembali pemisahan halaman setelah menambah teks atau mengganti gambar. Untuk membagikan versi yang tidak perlu diedit, gunakan Save As PDF di Word.
